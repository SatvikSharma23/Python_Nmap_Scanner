# Python_Nmap_Scanner
#### ● Usage : python3 Basic_Nmap_Scanner.py
#### ● Under this you will be asked for IP address and the three different scan options
This is the small Python-based nmap script that scans the network devices and look for open ports in it
We have three option of scan in this script:
1) TCP SCAN
2) UDP SCAN
3) Comprehensive SCAN
